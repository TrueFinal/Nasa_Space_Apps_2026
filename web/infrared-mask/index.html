How the mask works

The CWAVE band center must fall within the selected range. Invalid pixels and instrumental flags are excluded. Gaia DR3 marks nearby stars; SOURCE and OUTLIER remain visible for review.

CBAND retains the physical response width of each pixel. Selecting a range does not create a monochromatic image or confirm an object.

This analysis uses SPHEREx FITS data. Gaia supplies stellar positions; WISE provides context and adds no measurements to this spectrum.
